已注册 AutoClaw 账号的用户均可参与。法律实践赛道重点欢迎律师、企业法务、合规人员，以及需要处理合同和法律材料的用户。

## 参与方式

1. **关注官方账号**：小红书「智谱AutoClaw」、微信公众号「AutoGLM」或 X @AutoClawAIer。
2. **发布参赛内容**：选择一个赛道，在小红书、微信公众号或 X 发布原创使用案例。小红书内容文末须带上 #AutoClaw #智谱AutoClaw。
3. **提交投稿表**：填写注册 AutoClaw 使用的手机号、赛道、发布平台、账号名称和社媒发布链接；有独立网页、代码或成品链接的，同时填写「作品链接」。
   - 须先发布内容，再提交表单。仅提供成品链接、未提供有效的社媒发布链接，不计为有效投稿。

## 投稿赛道

1. **法律实践赛道（本期重点征集）**：分享法律检索、合同审查、多版合同对比、案件材料整理、文书起草或文件脱敏任务。建议展示来源核验、合同批注、事实时间线、证据目录或文书初稿。
2. 金融投研赛道：公司或行业研究、财报整理、企业尽调、持仓跟踪、测算模型或数据看板。
3. 自由创作赛道：生活、学习、办公、开发或多 Agent 工作流中的实际应用。
4. 视频创作赛道：创意短片、动画、3D 可视化、科普视频或游戏场景等视频作品。

## 作品内容要求（图文和视频均可）

参赛内容应让读者看懂以下信息：

1. **任务背景**：要解决什么问题，成果用于什么场景。
2. **使用过程**：输入了哪些材料或关键指令，AutoClaw 完成了哪些步骤。
3. **实际成果**：展示关键截图、文件、网页、工具或成片。
4. **使用经验**：人工核对或修改了什么，有哪些可借鉴的方法和待改进之处。
